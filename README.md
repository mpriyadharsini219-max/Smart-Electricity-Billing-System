# Smart Electricity Billing System ⚡

A Java + MySQL based Electricity Billing Management System developed to manage electricity bills efficiently.

## Features
- Consumer Login
- Admin Dashboard
- Unit Consumption Entry
- Automatic Bill Calculation
- Monthly Bill Generation
- Payment Status Tracking

## Technologies Used
- Java
- MySQL
- JDBC
- HTML
- CSS

## Modules
1. Admin Module
2. Consumer Module
3. Billing Module
4. Payment Module

## Future Improvements
- Online Payment Gateway
- Email Notifications
- Usage Analytics Dashboard
